- Recursion & Backtracking

- Heaps
- Hashing
- Graphs
- Dynamic Programming
- Greedy Algorithms

## Goals

- Strengthen core DSA fundamentals
- Practice time and space complexity analysis
- Build consistent interview problem-solving skills
- Prepare for coding rounds and software engineering interviews
